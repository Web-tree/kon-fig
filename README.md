# Kon-Fig

**One configuration standard. Any tool.**

Kon-Fig is an open, local-first, implementation-independent specification for discovering, composing, validating and securely resolving software configuration. It generalizes the [Agent Config Standard](https://github.com/Max-Levitskiy/skills/blob/main/standards/agent-config.md) concept (see [upstream project](https://github.com/Max-Levitskiy/skills)) beyond AI agents.

**Status: initial working draft (0.1.0-draft).** No stable release, certified implementation or published website is claimed.
